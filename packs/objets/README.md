# Compendium "Objets"

Dossier vide dans le dépôt : Foundry le compile en LevelDB directement ici, la première fois
qu'un document y est ajouté depuis l'interface (glisser un Item de type `gear` depuis le
monde vers ce compendium, ou "Créer un objet" directement dedans).

Réservé aux objets génériques (Item de type `gear`, cf. `scripts/data/item-data.js`) : objets
d'aventurier, composants, objets de quête, etc. — tout ce qui n'est ni une arme/armure
(compendium "Équipements"), ni un outil à bonus (compendium "Outils").
